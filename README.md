# Καθημερινά Fluency — Phase 5 (V1.4.0)

## Greek-content correction
This phase applies the standing orthography rule:
- preserve correct Standard Modern Greek spelling
- do not respell or simplify Greek
- do not anglicize Greek
- use full standard written forms in teaching content when a contracted form is not desired

Corrections include:
- `Κι εγώ!` → `Και εγώ!`
- `Κι εσένα;` → `Και εσένα;`

## Phase 5 feature: Fluency Workouts
Adds 3 cumulative workout sets:
1. Lessons 1–3 integration
2. Lessons 4–5 integration
3. Full Cycle 1 Fluency Challenge

Workouts include:
- mixed recognition
- sentence building
- recall
- independent free production
- cumulative material from earlier lessons
- no immediate one-lesson/one-worksheet repetition pattern

## Design rule
Fluency Workouts are cumulative and unlocked by lesson progress. They do not replace Review and they do not block the Fluency Path.
